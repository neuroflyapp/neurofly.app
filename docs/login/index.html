One entry point for the NeuroCause team’s statistics. The public research site and software do not require an account.

Open the statistics dashboard ↗Cookieless aggregate audience data, page performance and download counts. Protected by Cloudflare Access. Open edge traffic ↗Cloudflare request, visitor and security metrics, including traffic that never runs website JavaScript. Cloudflare sign-in required. Open Clarity ↗Heatmaps and masked session analysis only for visitors who opted in. Microsoft sign-in may be required.

The protected dashboard currently lives at stats.neurofly.app. Its established Access policy stays in place; this page never asks for a password. These sources measure different things: edge requests may include bots, the own counter excludes opt-outs, and Clarity sees only opted-in browsers. Do not add their totals together.
